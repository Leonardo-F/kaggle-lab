# Santa V11 Round 7 — local arithmetic program synthesis

Fixed original Dev100, untouched holdout. Rebuilt all candidates independently from the official input, using the R6 four constructors, union and restricted MILP. No prior solutions or graphs were used. R5/V10 score-only CSV read for comparison after solving. Four workers; per-ID SQLite commits, fingerprint checking and replay on resume. Several batches timed out but all 100 IDs subsequently completed with no route errors.

`synth.cpp` removes a selected node plus its exclusive dependency cone (targets pinned), rejects all downstream nodes as operands, then enumerates all one-step values of the retained independent operand set. Inverse arithmetic checks find one- or two-instruction replacements, or a three-instruction balanced join `(a op b) op (c op d)`. Intermediate values need not exist in the seed graph. Each rewrite strictly reduces node count; the two-pass algorithm is greedy, not globally exact. The mode-3 search does not exhaust all three-instruction chain forms. The unchanged register scheduler compiles each new graph; the portfolio picks the shortest legal program among the eight routes generated in this run. Single synthesis routes may regress.

## Reproduce
Linux binaries and C++ sources included. Run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run7.py /path/puzzles.csv --db new7.sqlite --jobs 4 --limit 12` repeatedly until complete. To resume existing checkpoint use `round7.sqlite` with unchanged files and Python environment. For synth compile `g++ -O3 -std=c++17 synth.cpp -o synth` (if recompiling, use a new DB). Report script `python reports/report7.py` expects puzzles.csv in the parent directory. This is a Dev100 result, not a full Kaggle submission. Do not use the checkpoint programs to initialize new independent research; regenerate graphs from raw puzzle inputs. Raw official datasets not included.
