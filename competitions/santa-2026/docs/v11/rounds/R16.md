## New experimental basis selector
- `variants/basis16/basis.cpp` extends the original free-basis constructor with an explicit list of optional preconstructed hubs. The Python runner compares default construction, no hub, up to three individually forced ranked hubs, and one ordered pair of the two best individual hubs. Each candidate runs independently from initial puzzle values, compiles the entire graph and runs both scheduling optimizers. Select by actual validated program length.
- 30 Dev100 IDs completed; 175 candidate programs: default 4,653, best without the pair (includes default and empty) 4,570, full portfolio 4,556. Twenty improved over the default, three strictly improved on all non-pair alternatives. Pair search adds 14 instructions of savings. Aggregate per-puzzle wall times 173.454 seconds (not elapsed time for the parallel batch).
- This is a narrow two-stage beam-like pilot, not exhaustive multi-hub search. The increased search budget is not matched against a same-runtime baseline; results are not a comparison against the complete integrated V11. No new holdout or full 1000 run. R8 holdout remains 49/100. No GitHub changes. Independent replay verification of 1,503 route instances includes previous checkpoint programs. Several bounded batches timed out before the final batch completed; completed records were preserved.

## Reproduction
Place official puzzles.csv one directory above this project; it is not bundled. From project root:
```
g++ -O3 -std=c++17 variants/basis16/basis.cpp -o variants/basis16/basis
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python variants/basis14/resume_groups.py --jobs 4 --limit 24
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python variants/basis16/run.py --jobs 4 --limit 100
python reports/report16.py
```
Existing databases are resumable. For fresh integrated reproduction use the original R12 integrated runner with a clean database; do not alter the original fingerprint. The reports use historical score-only comparisons for evaluation, not constructor inputs.
