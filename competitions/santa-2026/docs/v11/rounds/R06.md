# Santa V11 Round 6: exact arithmetic hypergraph selection

## Results
Fixed original Dev100, no holdout access. Four workers; per-ID SQLite commits, input and code fingerprint; interrupted batches resumed. Four fresh constructors (order, factor, bilayer, congruence) plus 8-round union provide the reduced baseline (16,489). No earlier program, graph, or submission was used as an optimization input. Previous score-only CSV was read after experiments for comparisons.

Restricted acyclic MILP (`exact_graph.py`, SciPy HiGHS) enumerates cross expressions among fresh candidate values, orders them by seed DAG order plus placement of alternative values, and selects a minimum number of expressions with dependency implications and exactly one definition per target. All 100 models returned status 0 (optimal within the restricted candidate graph and topology). MILP route alone: 16,487; reduced portfolio including MILP: **16,397**, 92 fewer (0.558%) than the matched reduced baseline; 56 improved, 44 equal, 0 worse for portfolio. MILP alone: 56/36/8 vs reduced baseline, due to graph/scheduling tradeoff. Compared with V10 16,494: 97 fewer; compared with R5 full nine-route 16,349: 48 more, 37/23/40. Score-only retrospective minimum vs R5 = 16,266; not a newly solved full portfolio. All 600 route programs and 100 winners independently validated.

Unrestricted cycle-cut MILP (`variants/cycle_graph.py`) removes fixed order and forbids selected edge cycles iteratively. 11/12 pilot IDs finished before batch interruption, 77 route programs and 11 winners independently validated. Only 1/11 found acyclic solution within 2-second overall model budget; 10 fell back to fresh seed; total 2,057 cycle cuts. Matched restricted portfolio score 1,615; with unrestricted route 1,614. Not a full Dev100 test, no general optimality claim. The topology-free model is currently inefficient; consider rank variables or SCC partition with local exact optimization.

No full ten-route fresh combination, no holdout and no full1000. No CP-SAT (ortools unavailable); SciPy MILP substituted. No GitHub modifications. Next: integrate restricted MILP into full R5 portfolio and add a register-pressure proxy, or design local rank-free exact windows; only then freeze and run holdout. All scores are instruction counts, lower is better. Global optimality not established.

## Reproduce
Linux x86-64 binaries included; source files included. Use Python 3.13, NumPy/SciPy, g++ C++17 if recompiling. Exact checkpoint fingerprints include the root Python/C++ sources and binaries; do not add or change root source files when resuming. Use a new DB if rebuilt.

From root: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run6.py /path/puzzles.csv --db new6.sqlite --jobs 4 --limit 20` (repeat until complete). For the cycle pilot, copy `variants/cycle_graph.py` and `variants/run6_cycle.py` to root, then run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run6_cycle.py /path/puzzles.csv --db cycle6.sqlite --jobs 4 --limit 1` to resume original interrupted pilot (last missing ID within first 12; limit means number of missing IDs). Remove the copied files after this to restore R6 fingerprint. Raw official data and previous solution/checkpoint files excluded from this archive. Current Dev100 winner CSV is not a complete Kaggle submission. See REPORT6.json and paired comparison files for validation and statistics.
