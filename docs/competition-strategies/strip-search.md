# 正方形装箱：偏置对角带与 L 形外扩

这轮在 `49bec68` 的旋转构造组合上继续。对角带先找更紧的排布，L 形外扩再把其中一部分排布迁移到更大的规模。两个方法都在 CPU 上确定性运行。每个 `n` 单独与原组合比较，完整平方数仍保留边长恰为整数的格点布局。

## 对角带怎样产生新排布

把坐标旋转 45°，令 `u=(x+y)/√2`、`v=(y−x)/√2`。容器的边长是 `L`，沿 `v` 方向的总宽为 `√2 L`。把 `q` 行斜排方块放进一条宽 `q` 的带，带的两侧沿 `v` 分别剩下 `a`、`b`，于是 `L=(a+q+b)/√2`。

- 在下侧与上侧的两个对角，用轴对齐单位方块填出阶梯。两侧允许的阶梯深度分别是 `floor(√2 a)` 和 `floor(√2 b)`，每个角的水平和竖直跨度也受 `floor(L)` 限制。
- 编号从 0 开始的第 `j` 行，可以沿 `u` 居中放置 `min(floor(2a)+2j, floor(2b)+2(q−1−j))` 块。行两端要离容器边界留出足够距离，靠近尖角的行因此更短。
- 容量只在余量跨过半整数或 `整数/√2` 时改变。程序枚举这些断点，用整数运算计算阶梯深度和行长，避免在恰好接触的断点上少算一块。边长的整数档如果限制了角部容量，在档位边界最多只能装下整数平方数，已经由格点布局覆盖。

例如 `n=18` 时，取 `q=2`、`a=3/√2`、`b=4/√2`。两行斜排分别放 4 和 5 块，两个角分别放 3 和 6 块。理想边长是 `3.5+√2≈4.914214`，原组合用的是边长 5 的格点。

## L 形外扩怎样迁移结果

若 `n` 块已放进边长 `L`，令 `k=floor(L)`。在右边填 `t×(k+t)` 块、上边填 `k×t` 块，可得到 `n+2kt+t²` 块，理想边长为 `L+t`。换一种写法，新块数是 `(k+t)²+(n−k²)`。所以一个好种子在超过整数平方数时所容纳的额外块数，能带到多个更大的规模。两个边带和原布局保持微小间隔，斜排构造也在导出前留出小间距，以抵御 CSV 十进制读写的舍入。

例如以 `n=65` 的旋转核心阶梯为种子，`k=8`。右侧补 9 块、上侧补 8 块得到 `n=82`，边长约 9.535534，原组合约为 9.949748。若某个外扩布局容量大于目标 `n`，可以删掉多余方块，再量最终包围边长。

## 1,000 题实测

| 候选组合 | 官方 v20 本地总分 ↓ | 比原组合边长缩小的题数 |
| --- | ---: | ---: |
| 原旋转构造组合 | 26.993155 | — |
| 原组合 + L 形外扩 | 24.607213 | 244 |
| 原组合 + 偏置对角带 | 23.832670 | 348 |
| 原组合 + 偏置对角带 + L 形外扩 | **23.634515** | **352** |

组合比分数基线低 **3.358640（12.44%）**，没有题目的边长增大。对角带使收益覆盖更多 `n`，L 形外扩单独补上了一些对角带难以达到的档位。组合的 352 个改进中有 185 个来自 `n>500`。最终保留 256 个对角带和 96 个 L 形布局。统计改进时忽略小于 `10⁻⁶` 的边长差，以免把数值间距当作算法收益。

原组合生成出的 CSV 与此前认证的文件 SHA-256 一致。新 CSV 在原始十进制文本和 pandas 数值读写两条路径上均通过 **1,000/1,000** 题，整份文件共 500,500 行。单项对照复用两条路径上六列文本完全相同的 v20 逐题结果，其余 640 个不同的检查项由同一评分器重算。评分器版本、文件指纹和示例见[机器可读结果](strip-search-results.json)。本地运行组合生成器约 6 秒，7 个进程认证约 4 分半。分数为本地复验记录，Kaggle 平台尚未评分。

下一轮可把仍用整数格点的 `n=29、30、41、42` 作为局部搜索样本。如果找到了边长更小且可认证的种子，先测外扩能贡献哪些额外改进，再决定是否扩大连续角度搜索。

## 复现

从仓库根目录运行。生成器只用 Python 标准库，官方认证使用已固定的 `mpmath` 和 `pandas`。

```bash
p=competitions/squares-in-squares
python -m pip install -r "$p/requirements.txt"
python "$p/algorithms/strip_search.py" \
  --output "$p/submissions/strip_search.csv" \
  --manifest "$p/experiments/results/strip-search-manifest.json"
python "$p/algorithms/certify.py" \
  --input "$p/submissions/strip_search.csv" --complete --workers 4 \
  --report "$p/experiments/results/strip-search-certification.json"
```

把生成器的 `--method` 改为 `diagonal` 或 `border` 可以重跑单项对照。每份 CSV 单独指定输出和认证报告路径。生成清单记录每题的边长、构造和种子，认证报告记录逐题结果与 CSV 的 SHA-256。

这两个构造家族的数学背景见 Erich Friedman, [Packing Unit Squares in Squares: A Survey and New Results，§2](https://www.combinatorics.org/files/Surveys/ds7/ds7v1-1998.pdf)。本实现自行推导计数并生成坐标。
